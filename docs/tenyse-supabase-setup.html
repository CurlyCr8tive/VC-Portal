Verified Consulting — Portal Build

Setting up your project's database

About 10 minutes, no technical background needed. This creates the account the dashboard's data will live in — under your name, on your card, so it's yours from day one.

Before you start

This costs $25/month, billed to whatever card you use to sign up. It's a real recurring cost, not a free trial — if you haven't already okayed that number with Cherice, do that first. You can cancel any time from the same account.

1

Create your account

Go to supabase.com and sign up — your email works fine, no need for anything special. This is the account that owns everything, so use the email and password you'll remember and want tied to Verified Consulting long-term.

2

Create an organization

It'll ask you to name an "organization" first — this is just a folder for your projects. Name it something like Verified Consulting.

3

Turn on the paid plan

In that organization's billing settings, switch from the free plan to Pro ($25/month) and add a card. This is the $25/month from the top of this page.

4

Create your project

Name it verified-consulting-portal (or anything recognizable). Pick the region closest to you — East Coast US is right for you and your clients.

It'll generate a database password — click to reveal it, then copy it somewhere safe (a password manager, or a note you won't lose). You likely won't need to type it yourself, but don't skip saving it.

Give it a minute or two to finish setting up before moving on.

5

Add Cherice to the team

In the organization's Team settings, invite:

chericeheron@gmail.com

This lets Cherice build inside your account without ever needing your login. You stay the owner the whole time.

6

Send Cherice two things

Open your project's Settings → API page (sometimes labeled "Data API"). You'll see two values — copy both and send them to Cherice:

Project URL — looks like https://xxxxx.supabase.co

anon / public key — a long string of letters and numbers

One thing not to send

That same API page also shows a service_role key, marked secret. Don't copy or send that one — only the anon / public key. If you're ever unsure which is which, just ask before sending anything.

Recap — send Cherice these two things when you're done

  • Your project's Project URL
  • Your project's anon / public API key
Stuck on any step, or a screen doesn't match this? Text or email Cherice — screenshot whatever you're looking at.
